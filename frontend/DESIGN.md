# TRACE / Аналитическое досье

Дизайн строится вокруг специфики кейса: восстановить структуру по наблюдаемым переводам. Визуальная метафора — рабочее досье аналитика, а не банковское приложение или универсальный dashboard.

## Характер

- Тёплый бумажный лист на нейтральном столе, чернильный текст, ржаво-оранжевая сигнальная краска.
- Горизонтальный индекс разделов 01–04, линейки вместо теней и округлённых карточек.
- Georgia для названий разделов; Bahnschrift для марки и крупных цифр; системный гротеск для чтения; моноширинный шрифт для GID и служебных подписей. Все шрифты с локальными fallback, без внешних запросов.
- Граф — тёмная чертёжная поверхность с координатной сеткой, маркерами seed и направленными связями.
- Правая колонка — аналитические заметки. «Начальная точка» вычисляется из текущей выборки по priority_score; это не случайный декоративный клиент.
- Роли остаются согласованными по цвету в графе, списке и карточке. Цвет не является единственным носителем смысла: есть текстовые названия.

## Токены

Основные значения находятся в :root файла styles.css:
--desk, --paper, --ink, --muted, --line, --signal, --map, --mono.

Не добавлять новые независимые оттенки для каждой кнопки или таблицы. Сигнальный цвет означает действие/акцент, а не доказанную противоправность.

## Поведение

Наведение или клавиатурный фокус на узле подсвечивает его прямые связи. Приглушённые узлы остаются доступны для выбора. Карточка клиента открывается отдельным листом справа.

На телефоне сохраняется порядок чтения: заголовок, поиск, численные данные, схема, заметки, реестр. Таблица прокручивается внутри своего блока. Учитывается prefers-reduced-motion.

Все численные подписи берутся из загруженного graph.json. Отметка глубины — максимальное значение depth в данных, не обещание полного охвата переводов.
