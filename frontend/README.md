# TRACE — фронтенд команды LLM-Solo

Статическое приложение без сборки, CDN и npm-зависимостей.

Для Muha: [отдельный контракт бэкенда](../BACKEND_CONTRACT.md) с форматом JSON и вариантами подключения.

## Запуск

Из корня репозитория: `python -m http.server 8000 --bind 127.0.0.1`.
Откройте `http://127.0.0.1:8000/frontend/`.
По умолчанию загружается `out/graph.json`; кнопка «Импорт данных» открывает другой локальный JSON без отправки на сервер.
Если файла нет, приложение предлагает импорт или повторную загрузку.

## Структура

- `index.html` — каркас, навигация, фильтры и диалог клиента.
- `styles.css` — тема и адаптивные состояния.
- `DESIGN.md` — визуальная концепция «Аналитическое досье», палитра и правила для новых экранов.
- `app.js` — обзор, SVG-граф, фильтры, таблица, кластеры, импорт/экспорт.
- `data.js` — lossless-парсер GID, валидация, индексы связей, CSV.
- `data.test.cjs` — тесты контракта; запуск `node --test frontend/data.test.cjs` из корня.

## Контракт для бэкенда

```json
{
  "nodes": [{
    "gid": "100000000000000001",
    "role": "transit",
    "cluster_id": 0,
    "priority_score": 0.65,
    "role_score": 0.8,
    "evidence": "Численное обоснование роли и приоритета",
    "depth": 1,
    "is_seed": false,
    "in_kzt": 100000,
    "out_kzt": 90000,
    "truncated_by_depth": false
  }],
  "edges": []
}
```

Ребро: `{ "src": "...", "dst": "...", "sum_kzt": 90000, "n_tx": 3 }`.
Оба конца должны присутствовать в `nodes`. `gid`, `src`, `dst` передавать **строками**: int64 не помещается в безопасный JavaScript Number. Для совместимости текущий числовой JSON читается как текст lossless-парсером; не заменять это на `response.json()`.

Роли: `coordinator`, `consolidator`, `distributor`, `transit`, `terminal`, `peripheral`.
Скоры в пределах 0–1; в интерфейсе показаны на шкале 0–100. Это оценки алгоритма, не вероятность виновности. Степени узлов вычисляются по уникальным контрагентам. Роли и скоринг фронтенд не пересчитывает.

## Поведение интерфейса

- Обзор показывает 150 приоритетных узлов, отдельный граф — 180; кнопка позволяет показать всю выборку.
- Точный поиск GID и «Показать связи на графе» раскрывают всех прямых соседей независимо от фильтров. Поиск не ограничен демонстрационными узлами.
- Масштабирование кнопками/колесом, перемещение перетаскиванием; окраска по роли или кластеру.
- Наведение или фокус клавиатуры выделяет прямые переводы узла. Заметка «Начальная точка» открывает окружение самого приоритетного клиента текущей выборки.
- Кластеры считают внутренний оборот только по рёбрам между участниками одной группы.
- Отсутствие исходящих на глубине 4 отмечено как граница данных, а не доказательство конечного получателя.
- Экспортирует текущий отфильтрованный и отсортированный список (не только страницу), колонки `rank,gid,role,priority_score,why`.
- GID в CSV точный, но Excel может округлить его при автоматическом открытии. Импортируйте колонку GID как текст.
- `Escape` закрывает карточку; `/` переводит фокус в поиск. На узлы графа можно переходить с клавиатуры.

При подключении API замените URL в `loadDefault()` в `app.js`, сохранив загрузку ответа через `.text()` и `MoneyGraph.parse()`.
