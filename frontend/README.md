# TRACE — фронтенд команды LLM-Solo

Статическое приложение без сборки, CDN и npm-зависимостей. Основа импортирована из `origin/Zhans`, коммит `bdbbb65`. Python рассчитывает аналитику и экспортирует один JSON; интерфейс отображает результаты. [Контракт данных](../BACKEND_CONTRACT.md).

## Запуск

Из корня после установки Python-зависимостей:

```powershell
.\.venv\Scripts\python.exe -m moneygraph --data data --out artifacts --serve
```

Откройте `http://127.0.0.1:8765/frontend/`. Экспорт копирует интерфейс в `artifacts/frontend/`; он читает соседний `artifacts/graph.json` через `../graph.json`. Сервер слушает только `127.0.0.1`. Отдельный API и Go не нужны.

Без сервера откройте `artifacts/frontend/index.html` и импортируйте `artifacts/graph.json` кнопкой «Импорт данных». Можно использовать и исходный `frontend/index.html`. Файл читается в браузере и никуда не отправляется. Если автоматическая загрузка не удалась, приложение предлагает импорт или повтор. Устаревшие файлы с другого пути не подставляются.

## Структура

- `index.html` — навигация, фильтры и диалог клиента.
- `styles.css`, `DESIGN.md` — тема «Аналитическое досье» и правила оформления.
- `app.js` — обзор, граф, карточки, локальные страницы операций, импорт и экспорт.
- `data.js` — lossless-парсер GID, валидация, индексы связей и операций, CSV.
- `data.test.cjs` — исходные тесты контракта из ветки Zhans.
- `backend.test.cjs` — регрессии интеграции со статическим экспортом Python.
- `package.json` — только граница CommonJS для тестов; сборки и зависимостей нет.

## Данные и поведение

Полный `graph.json` содержит `nodes`, `edges`, `transactions`, `snapshot_id`, метаданные расчёта, кластеры и рейтинг. Минимальный старый `{nodes, edges}` тоже читается: карточка объясняет, что операции в таком файле отсутствуют. Отсутствующее поле не считается рассчитанным нулём.

- GID хранится строкой во всех элементах браузера. Загрузка через `.text()` и `MoneyGraph.parse()` сохраняет даже старые числовые int64 без округления.
- Обзор показывает 150 приоритетных узлов, граф — 180; можно раскрыть всю выборку. Точный поиск и «Показать связи на графе» выводят всех прямых соседей независимо от фильтров.
- Масштабирование кнопками и колесом, перемещение перетаскиванием; окраска по роли или кластеру. Наведение и фокус клавиатуры выделяют прямые переводы.
- Кластеры считают внутренний оборот по рёбрам между участниками одной группы. Степени узла считают уникальных контрагентов без самопереводов. Роли и скоринг не пересчитываются в браузере.
- Карточка показывает основания роли, все сработавшие правила, причины `peripheral`, вклад в приоритет, временные доли и сопоставленный объём. Подписи означают гипотезу, не виновность.
- Отсутствие исходящих на depth=4 — граница данных. Для seed отмечается неполнота входа. Месячные обороты не являются балансом счёта.
- Суммы в карточке, реестре и операциях имеют два десятичных знака. Компактные обзорные показатели могут использовать тысячи и миллионы.
- Операции индексируются локально и показываются страницами по 100. Переход страницы и открытие клиента не делают сетевых запросов. Даты — `YYYY-MM-DD`, без вымышленного времени; `row_id` — номер строки экспорта, не банковский ID.
- Повторяющиеся операции с разными `row_id` сохраняются. Некорректные даты, суммы, ссылки на отсутствующих клиентов и повтор `row_id` отклоняются до замены открытого графа.
- Более поздний выбор файла имеет приоритет над запоздавшей автоматической загрузкой или чтением предыдущего файла.
- CSV-экспорт включает весь текущий отфильтрованный и отсортированный список, не только страницу. В Excel импортируйте GID как текст.
- `Escape` закрывает карточку; `/` переводит фокус в поиск. Узлы графа доступны с клавиатуры.

JSON и HTML содержат исходные связи клиентов: храните их в том же режиме доступа, что и выданные данные. UI не подключает внешние шрифты, CDN и LLM.

## Проверка

```sh
node --test frontend/data.test.cjs frontend/backend.test.cjs
```

Тесты используют синтетический JSON и подмену чтения статического файла. Для них не нужны ключи, внешняя сеть или данные хакатона.
