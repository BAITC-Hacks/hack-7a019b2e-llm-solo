# Объяснения и наблюдаемые факты — контракт для фронтенда

Основной запуск и три обязательных CSV не изменились. Все поля ниже формирует `python -m moneygraph --data data --out artifacts`. Версия правил: `roles-v3-witnesses-motifs`; `schema_version=1`, изменения JSON добавочные. Фронтенд не редактировался: отображение новых секций — задача команды интерфейса. Поле `limitations` уже поддерживается существующей карточкой.

## Поля узла в graph.json и metrics.json

| Поле | Содержимое / способ показать |
| --- | --- |
| `temporal_evidence` | `matches` и `strict_matches`: `in_row_id`, `out_row_id`, `cents`, `lag_days`. По row_id открыть исходные строки массива `transactions`. `matched_cents`, `strict_matched_cents`, `same_day_matched_cents`, `total_in_cents`, `total_out_cents` позволяют сверить итог. |
| `bridge_evidence` | `null` либо `path` (три строковых gid), `transaction_row_ids`, `legs` с датами/сотыми и `limitation`. Показывать A→клиент→B. Роль coordinator требует такой путь помимо прежних порогов. |
| `motifs` | Список `cycle`, `repeat_amount`, `burst`; пустой список означает отсутствие этих шаблонов в наблюдаемых данных. |
| `observed_facts` | По одному детерминированному примеру каждого найденного мотива: `kind`, `summary`, `transaction_row_ids`, точные `transactions`, `limitations`, счётчики. |
| `motif_summary` | Короткие описания найденных мотивов; может быть пустым. |
| `role_stability` | `stable`, `profiles` с ролями в base/relaxed/strict, `scope`, `limitation`. Подпись: «Роль совпала в трёх проверенных профилях», не «роль достоверна». |
| `limitations` | Ограничения конкретного узла и смысла вывода. |
| `next_query` | Предлагаемый следующий запрос аналитика; сам запрос никуда не отправляется. |

`row_id` — номер строки внутри канонического снимка, не банковский идентификатор операции. Дубликаты исходных строк сохраняются отдельно. Все gid — строки; денежные `cents` — целые сотые KZT.

FIFO расходует каждый входящий и исходящий объём не более одного раза в каждом сценарии, допускает разделение и объединение. Самопереводы исключены. Основной сценарий допускает совпадение дат; строгий запрещает его. Ни один сценарий не доказывает происхождение именно тех же денег. Направленный путь — структурное свидетельство: последовательность дат на нём не утверждается.

Циклы ограничены длиной 2–6, `chronology_checked=false`. Для каждой связи показан один реальный перевод. Повтор — минимум три перевода одной суммы одной направленной пары. Всплеск — минимум пять переводов одного направления за день. Самоперевод считается один раз в исходящем всплеске, исключён из циклов и повторов. Никаких утверждений об умышленном дроблении или возврате тех же денег.

## Обзоры верхнего уровня graph.json

- `components`: все компоненты, включая изоляты; `component_id`, `n_nodes`, `n_seed`, `n_edges`, `sum_kzt_internal`, `top_gids` (до 10), `role_counts`, `motif_counts`. Маленькая компонента имеет собственный топ независимо от общего рейтинга.
- `motif_rankings`: по каждому мотиву `n_nodes` и `top_gids` (до 20). Числа относятся к узлам, не к числу циклов.
- `sensitivity_profiles`: полные конфигурации base/relaxed/strict. Пороговые количества меняются на ×0.8 с округлением вниз / ×1.2 вверх; положительные остаются ≥1. Веерный коэффициент ×0.8/1.2, диапазон O/I расширяется/сужается вокруг середины ×1.2/0.8, минимальная временная доля ×0.9/1.1 с максимумом 1, квантиль координатора ±0.05. Признаки, кластеры, временное окно и приоритет фиксированы. Это ограниченный анализ чувствительности, не вероятность правильной роли.
- `analysis_sha256`: хеш узлов, обзоров и конфигураций профилей; входит в `snapshot_id`. Проверка `moneygraph.verify` заново строит свидетельства по исходным переводам и сверяет их с сохранённым JSON. Хеш не является цифровой подписью.

## Проверено на официальном наборе

Расчёт: 5.839 секунды, 2248 узлов, 105 кластеров, 35 компонент, топ-50. Все 57 координаторов имеют конкретный путь. Структурный цикл найден у 303 узлов, повтор суммы у 79, направленный всплеск у 76. Число 155 из прежнего исследования использовало другое определение всплеска; здесь оно не заявляется. Основные роли не изменились; evidence координаторов уточнён. Сопоставленные объёмы обеих временных моделей совпадают с ранее рассчитанными метриками.

Роль совпадает в трёх проверенных профилях у 2037 узлов, меняется у 211. Все 77 тестов Python прошли общим прогоном; затем добавлен и отдельно пройден 78-й тест на подмену перевода-свидетеля, повторно проверен запрет coordinator без пути. 83 Node-теста прошли. Перестановка входных строк покрыта тестами новых модулей и экспорта. Повторная межверсионная проверка именно v3 остановилась на системном запуске Python 3.11 (Unable to create process); это не выдается за успешную проверку. Ранее подтверждённая межверсионная идентичность относилась к v2.
