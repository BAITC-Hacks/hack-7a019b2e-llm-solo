# Проверка требований и принятое решение

Источник фронтенда: `origin/Zhans`, коммит `bdbbb65`, `BACKEND_CONTRACT.md` и каталог `frontend/`. Они перенесены выборочно с сохранением рабочего Python-ядра. Второй источник — приложенный `BACKEND_HANDOFF.md`. После проверки пользователь окончательно выбрал **Python + JSON + HTML/JavaScript**.

## Реализация

Python загружает и сверяет Parquet, рассчитывает роли, кластеры и приоритеты, формирует три обязательных CSV. Полный `artifacts/graph.json` содержит все узлы, связи, операции, кластеры, рейтинг, конфигурацию, версии и хеши. TRACE строит локальные индексы и показывает карточки, связи и страницы переводов из одного загруженного файла. Отдельного API и Go нет.

Запуск: `python -m moneygraph --data data --out artifacts --serve`, интерфейс: `http://127.0.0.1:8765/frontend/`. Это раздача готовых файлов с loopback; анализ не выполняется по HTTP-запросам. Без сервера можно открыть `artifacts/frontend/index.html` и импортировать JSON. Автономный `report.html` сохранён.

## Уточнения к handoff

| Пункт | Принятое решение |
| --- | --- |
| Запуск starter.py | Используется пакет moneygraph; starter — исходная заготовка организаторов. |
| Предлагаемые REST-методы | Их пользовательские сценарии реализованы локально: очередь, точный поиск, карточка, связи, переводы, кластеры. Сетевой API не создаётся. |
| Метрики нужно доставать из HTML | Уже существовал metrics.json; теперь всё нужное для TRACE находится в graph.json. |
| ID | Во всех JSON gid/src/dst и списки ID — строки. В Python/CSV — int64. |
| Точность денег | Вход проверяется до сотых, сверка выполняется в целых тиынах. В JSON операций и связей есть cents; UI показывает два знака. |
| CSV с BOM | Обязательные Python CSV — UTF-8 без BOM; браузерный экспорт — с BOM. |
| Номер операции | row_id — индекс канонически отсортированного экспорта. Это не банковский ID и не исходный номер строки Parquet. Одинаковые операции сохранены. |
| Дата | YYYY-MM-DD; время внутри дня неизвестно. |
| Версия результатов | Весь интерфейс использует один атомарно записанный graph.json. snapshot_id описывает входы, правила и CSV; время выполнения в идентификатор не входит. |
| PageRank/HITS/SciPy | Не используются и не добавляются. Центральность betweenness вычисляется точно по умолчанию. |

SHA256 трёх CSV в JSON позволяет проверить соответствие выгрузок. Запись всех файлов каталога не является общей транзакцией: при сбое следует повторить расчёт. Браузер не читает CSV и операции разных запусков по отдельности.

## Выполненный объём и следующий этап

Подключение TRACE, полный JSON, проверка идентификаторов/дат/сумм/повторов и P0 правил выполнены. Транзит требует совместимости времени и объёма с поддержкой разделения и объединения сумм; peripheral содержит причину. Результат на официальном наборе — 26 transit вместо 65, а не заранее заданное число.

P1 остаётся отдельно: циклы, повторы сумм, календарные события, обзоры компонент/мотивов и событийное основание coordinator. Эти возможности не объявляются выполненными экспортом JSON. LLM в обязательном сценарии отсутствует.
