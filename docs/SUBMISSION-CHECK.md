# Финальная проверка сдачи — 23.09.2026

Обновление v3: подключены переводы-свидетели, мотивы, обзоры компонент и чувствительность ролей. Последние результаты и точные границы проверки — [BACKEND-EXPLANATIONS.md](BACKEND-EXPLANATIONS.md). Приведённые ниже межверсионные замеры и количество 53 Python-теста относятся к предыдущей версии v2.

## Одна команда расчёта

После установки Python 3.11/3.12, зависимостей из `requirements.txt` и размещения трёх исходных Parquet в `data/`:

```powershell
.\.venv\Scripts\python.exe -m moneygraph --data data --out artifacts --serve
```

Откройте `http://127.0.0.1:8765/frontend/`. При занятом порте добавьте `--port 8766`. Без сервера запустите ту же команду без `--serve` и откройте `artifacts/report.html`.

Готовые файлы дополнительно проверяются без их изменения:

```powershell
.\.venv\Scripts\python.exe -m moneygraph.verify --data data --out artifacts
```

## Воспроизводимость и передача

Ранее чистая установка закреплённых зависимостей и расчёт проверены на Python 3.11.9 и 3.12.14; три CSV побайтово совпали, перестановки строк исходников не меняют результат. Повторное создание ещё одного venv в финальной сессии остановилось из-за заполнения диска. Его незавершённый временный каталог удалён, место освобождено; рабочее окружение и данные сохранены. Этот неудачный этап не выдаётся за успешную новую установку.

После освобождения места текущий код повторно запущен в обоих подготовленных окружениях: Python 3.12.14 — 4.551 секунды, Python 3.11.9 — 5.426 секунды. `pip check` в окружении 3.11 не нашёл конфликтов. Все три CSV и содержательные поля JSON совпали, перестановки строк с seed 7 и 91 также прошли. Отчёт — `artifacts/verification/reproducibility.json`.

Код, README и тесты передаются через выданный командный GitHub. Исходные данные, CSV, JSON и HTML не коммитятся; обязательные результаты находятся в `artifacts/` и передаются разрешённым организаторами способом. После push отдельно нажмите «Сдать решение» на платформе: наличие коммита не подтверждает приём платформой.

Роли — проверяемые гипотезы. Тесты подтверждают контракты и воспроизводимость, но не accuracy: истинные метки ролей отсутствуют. Раздача файлов предназначена для локального просмотра, а не банковского многопользовательского сервиса.
