# Соответствие ТЗ: «Граф денег»

| Обязательное требование | Реализация и проверка |
| --- | --- |
| Один запуск от трёх Parquet до трёх CSV, <5 минут | `python -m moneygraph --data data --out artifacts`; точная центральность, полный прогон на выданных данных около 4–7 секунд на текущей машине; run.json содержит время и хеши |
| Все 2248 узлов, роли, scores, evidence | validate_outputs проверяет множество gid, enum, заполнение, [0,1], длину evidence≤200; официальный acceptance-тест проходит |
| Формальные критерии каждой роли | README «Формальные критерии ролей», config/roles.json, classify() и объяснения в карточках; тестовые мотивы всех шести ролей |
| Кластеризация и сводки | Взвешенная Louvain-проекция, отдельные изоляты; 105 кластеров на текущем наборе; n_nodes, n_seed, sum_kzt_internal, top_gids, hypothesis |
| Top≥20 + граф со стрелками, роли/кластеры, поиск gid | top-50, локальный Canvas-интерфейс; проверены поиск большого gid, изолят, depth=4, фильтры и скачивание CSV |
| Локальная воспроизводимость без платного сервиса/GPU | Python CPU, фиксированные версии, нет сетевых обращений и CDN в основной цепочке |
| Осторожность выводов и ограничения | Гипотезы в evidence; depth=4 не terminal; seed исключён из выводов по O/I; score не вероятность виновности |
| README, схема решения и демо | Корневой README содержит команды, критерии/пороги, Mermaid-диаграмму и сценарий пяти минут |
| Масштабирование до ~1 млн узлов | Раздел README с заменой движка/хранилища, ограничением вычислений и подграфами UI |

Дополнительно реализован временной признак совместимости потоков за 0–2 дня и карточка следующего запроса аналитика. Не реализованы LLM-чат по графу, обучение на размеченных ролях, циклы и эксперимент по удалению узлов: это опции ТЗ, не заявленные возможности MVP.

Приёмка не означает подтверждённую точность ролей: ground truth отсутствует. Код сохраняется в рабочей ветке `Muha`; сдача на платформе выполняется отдельно командой. Выгрузки находятся локально в artifacts/ и не публикуются автоматически. Прежний независимый Node-каркас проходит все 66 текущих тестов; история уточнения проверки RSS — в QA-RESOLUTION.md.
